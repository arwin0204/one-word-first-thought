A tiny deterministic Python program that writes a single word — apophenia — the first thought on AI, to entry.txt. Apophenia is the human (and machine) habit of seeing meaningful patterns in random noise: the very thing an AI does all day, and the first word that came to mind.

## Run it

```sh
python3 main.py
```

By default it writes to `/output/entry.txt`; set `OUTPUT_PATH` to write elsewhere, e.g. `OUTPUT_PATH=entry.txt python3 main.py`.
